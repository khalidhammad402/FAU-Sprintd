# DigitalHeat: submission for the reference house

Everything the case asks for, generated by one command from the code in this repository.

## Key figures (reference house, Basel 2025)

| | |
|---|---|
| Servers per house | **3 x 1 kW** |
| Heat demand covered by servers | **45.7 %** (14,310 of 31,307 kWh; the rest from the backup heater) |
| Heat dumped | **1,227 kWh** (7.9 % of the server heat) |
| Utilisation | **85.9 %** |
| Missed deadlines | **0.06 %** of jobs (22 of 34,645) |
| Electricity cost | CHF 6,458 (19,422 kWh at 0.3325 CHF/kWh) |
| Value of the heat used | CHF 1,903 |
| Computing income | CHF 52,685 (2.71 CHF per server-hour) |
| **Break-even computing price** | **0.235 CHF per server-hour** |

> Electricity costs 6,458 CHF, the heat used is worth 1,903 CHF. The model does NOT pay off if computing sells for less than 0.23 CHF per server-hour (achieved here: 2.71 CHF), or if electricity costs more than 3.85 CHF/kWh at these computing prices (used: 0.33). Hardware, installation, maintenance and network costs are NOT included: the margin per server-hour (2.48 CHF) must also pay for those.

## Reproduce

```
python -m live.measure            # laptop on battery: measures the real job
python make_reference_case.py      # data/reference_house/ (3 servers, 35 kWh tank, 2025 jobs)
python -m sim.submission --live    # this folder
```

Live demo: `python -m live.broker`, `python -m live.agent --server-id H1-S1 --host localhost`, `python -m live.master --data-dir data/reference_house --start <date>`.
